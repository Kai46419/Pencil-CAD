# PencilCAD Build 28 – Start hier

Dieses Paket enthält das vollständige Xcode-Projekt einschließlich `Vendor/OCCT.xcframework` und `Vendor/PencilSheet.xcframework`. Öffnen: `PencilCAD.xcodeproj`, Schema `PencilCAD`.

Änderungen: `BUILD_28_AENDERUNGEN_UND_TESTS.md`. Prüfnachweise und Grenzen: `Pruefprotokolle/BUILD_28_ABNAHME.md`.

Dieser Stand wurde virtuell im Simulator geprüft. Er wurde **nicht** auf das abgezogene iPad installiert. Beim nächsten Gerätetest besonders prüfen: Mittelpunktbogen an eigenen Linien, beide Seiten des Tangentialbogens, Text auf/über/unter einem Bogen, Winkel an schrägen Linien sowie Namen und fühlbares Feedback im Stift-Werkzeugrad.
